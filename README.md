# Neon Number Checker

This program checks whether a given number is a Neon Number.
A Neon Number is a number where the sum of the digits of its square equals the original number.

### Example:
-Input: 9
-Calculation: 9² = 81 → 8 + 1 = 9
-Output: `9 is a Neon Number!`

---

##  How to Run

### Running the Python Program
1. Ensure you have **Python** installed (version 3+ recommended).
2. Open a terminal or command prompt.
3. Navigate to the project directory:
   ```bash
   cd NeonNumberChecker
   ```
4. Run the script:
   ```bash
   python neon_number.py
   ```
5. Enter a number when prompted and check if it's a Neon Number!

### Running the Java Program
1. Ensure you have **Java (JDK 8 or later)** installed.
2. Open a terminal or command prompt.
3. Navigate to the project directory:
   ```bash
   cd NeonNumberChecker
   ```
4. Compile the Java file:
   ```bash
   javac NeonNumber.java
   ```
5. Run the compiled program:
   ```bash
   java NeonNumber
   ```
6. Enter a number and check if it is a Neon Number.
